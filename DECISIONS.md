- 2026-11-12 02:05 — `reasoning_effort: "low"` is the default on every chat call. Hidden reasoning tokens otherwise consume `max_tokens` (observed finish=length at 150 tokens with 148 reasoning tokens).
- 2026-11-12 02:05 — Images are always sent as `data:` URIs read from `.image-cache/`; the API refuses URLs whose robots.txt disallows fetching (picsum does).

- 2026-11-12 02:10 — Budget split: `MODEL_BUDGET_USD=50` hard, `MODEL_BUDGET_RESERVE_USD=10` kept for final QA and recordings. Normal runs refuse at $40; only processes started with `AI_FINAL=1` may spend into the reserve. Nobody raises either without a human.
- 2026-11-12 02:10 — Identical requests are served from `.ai-cache/` at $0 and labelled `cached` in traces. This is a request cache, not the labelled "replay" fallback mode (that comes in Milestone 10 and is labelled separately in the UI).
- 2026-11-12 02:40 — `tool_choice` must be `"auto"` on the Meta Model API (`"required"` and named choices return 400). The agent is told to use tools in its system prompt instead; the client ignores `toolChoice`.
- 2026-11-12 03:00 — Replay fallback chooses the recorded run by (viewer, weekend, budget) similarity and re-validates its trips against the live store, so a replay can never show a host who since turned hosting off or a ride that filled up. Labelled REPLAY in the UI and in traces.

Food with a local host is $18/day (hosts cook, locals know the cheap spots), $35/day otherwise; presets are $60/$100/$150/$300. Flights by distance band ($150/$180/$230/$300 round trip).

- 2026-11-12 18:40 — Open Door tiers: `friends` = degree 1, `fof` = degree 2 through a named mutual, `network` = also people who share a group with the host. Reach is computed by code from the graph (`openDoor.ts`); the host's agent is told the result and cannot widen it. `openToHosting`/`hostingNote` are derived from the policy so every older code path (cards, validator, eval) sees the same truth.
- 2026-11-12 18:50 — Travel style quotes must appear in the user's own content (≥70% word overlap after normalisation) or the line is dropped; other agents receive only the kept lines, never evidence or ids. The UI never says "personality".
- 2026-11-12 19:00 — Availability: `busyDates` is no longer read anywhere. Sources are event RSVPs (code), the person's posts the requester can see, and conversations the requester is in with that person. Muse (`muse-ember-1.0`) extracts dated statements with quotes; code verifies the quote is in the source and decides per date. "Unknown" is a first-class state; confirmation is a drafted question the user approves. The viewer's own weekends are only "busy" when they RSVP'd somewhere else.
- 2026-11-12 19:10 — Host agents answer through a strict JSON schema; code then scrubs addresses, phones/emails, "because…" clauses, schedule-reason words, third-party names not written into the policy, and any 5-word quote from the host's own posts/chats, and drops fit reasons whose evidence is not in the policy or style lines. Code also forces "no" when the traveler is outside the tier or the host is busy, regardless of the model. The traveler's name is stripped from every outgoing message by code.
- 2026-11-12 19:15 — Reveal order: traveler accepts the anonymous fit → host sees an anonymous card → host "See who" → both revealed → host's final yes opens a Messenger chat seeded with connection facts. Declines by a host's agent are shown to the traveler as "a host said no" and never reach the host.
- 2026-11-12 19:20 — Negotiation candidates are chosen by code (door open to the traveler, couch offered, in the trip city, not inferred busy), capped at 3, 2 rounds per host; asks run in parallel to keep the whole thing ≈25 s.
- 2026-11-12 16:00 — Pivot, branch `reconnect` (off `travel`): the product is reconnection, not travel. Judge and mentor feedback: travel is niche and "AI planning events" automates a solved problem. The unsolved one is before the plan: silence has no notification, reaching out after silence feels wrong, and group asks die unanswered. Travel becomes one plan shape ("visit") inside Reconnect; Open Door's agent-to-agent negotiation stays in the code but leaves the pitch.
- 2026-11-12 16:05 — Drift is computed in code, never by a model (`src/lib/reconnect/drift.ts`, ported from the `reconnect-prototype` branch's sleep math): a real contact is a two-way chat (both people sent within 48 h, in a DM or a group chat they share), an event both went to, or a photo both are tagged in. Likes and reactions never count. Rhythm = median gap between real-contact days over the last 180 days (older meetups don't stretch it), clamped 7–120, default 30 with fewer than 3. Ratio <1 awake, 1–1.5 sleepy, >1.5 napping; no contact at all reads as napping with "no real exchange we can see".
- 2026-11-12 16:05 — "I miss them" is private by construction: picks live only in the store keyed by the picker, the API returns only the viewer's own picks plus the `mutual` boolean, and the other person is told only at the moment both exist. Three picks are seeded (Nadia→Maya, Cole→Maya, Harper→Cole) so the mutual moment can happen on stage; this is seed data, not a model answer, and is listed in README.
- 2026-11-12 16:10 — Why-now: Muse Spark writes one line and cites ids from a shared-history index that code built (both people in every item, only what the viewer can see). Code refuses the nudge if any cited id is missing or is the trigger post with no other citation, if the line exceeds 30 words, or if it contains a mood/health/guilt word (`BANNED` in `whynow.ts`, including "miss(es) you" and "too long"). A dropped nudge is cached with its reason and shown as a reason, never as text. One unprompted nudge per person per day; friends only.
- 2026-11-12 16:15 — The gathering agent is the Discover loop pointed at a person or crew: `get_context` (code: people, their recent posts, shared history, 6 weekends with quick availability, events in both cities, rides), the existing `infer_availability`, `estimate_cost` (visit = travel pricing with host lodging; out-of-town event = same; in-town hangout = seeded $28 flat; call = $0), `propose_plans`. Validation re-checks people (visible), dates (future, ≤7 days), event/ride ids, attaches a friend's ride when one exists, sets the host to a target who lives there, recomputes cost, strips model-written dollars, and attaches each person's availability with quotes as sources. An RSVP to the plan's own event marks that person likely free for that day (code).

"I'm in" RSVPs the Event and notifies the owner; the owner confirms last and only after someone joined. The agent never sends anything.
